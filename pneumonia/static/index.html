Pneumonia X-ray Classifier

Course project demo: small CNNs trained on PneumoniaMNIST (28×28 chest X-rays, normal vs pneumonia).

Research / education only. Not a medical device; never use it for diagnosis.

Model and decision threshold

Lower threshold: fewer missed pneumonia cases but more false alarms. Metrics below are on the 624 held-out test images. Note: picking the threshold that looks best here would be tuning on the test set, so in the report the threshold is chosen on validation data only.
